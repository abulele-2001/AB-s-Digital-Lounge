# AB’s Digital Lounge - Print & Internet Café Website

A modern pink-and-white professional web platform built for **AB’s Digital Lounge** located in **Bluewater Bay, Gqeberha**, featuring online document printing orders, finishing options, internet café workstation bookings, live order tracking, and a built-in staff administration dashboard.

## Features Included

1. **Home Page**: Welcome banner, quick highlights for document printing, finishing, internet café access, and live tracking.
2. **Our Services**: Detailed breakdown of laser printing, photocopying, scanning, binding, laminating, and typing services.
3. **Place an Order**: Customer form to upload documents, select color mode, single/double sided, number of copies, and finishing options (stapled, spiral binding, laminating).
4. **Book a Service**: Reservation system for computer workstations, scanning slots, and secretarial assistance with date and time slot pickers.
5. **Track My Order**: Customer order status tracker (Pending, Processing, Ready for Collection).
6. **Administrator Dashboard**: Separate staff portal to view incoming customer orders, update order statuses, manage bookings, and view daily business activity.
7. **Contact Us**: Contact details, operating hours, and location information for Bluewater Bay, Gqeberha.

## Publishing on GitHub Pages

1. Create a repository on GitHub (e.g. `abs-digital-lounge`).
2. Upload `index.html` and `README.md` to the main branch.
3. Go to **Settings** -> **Pages**, select **Deploy from a branch** (`main` / `root`), and save.
